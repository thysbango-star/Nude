Meet Nebula

Nebula lives in a side panel. It reads a page only after you share it, and every answer says what it used.

  • Shopping, research, study and focus modesEach mode changes Nebula's quick actions. Shopping mode compares prices and builds outfits from the products on the page.
  • Lights up what it changesWhen Nebula highlights something on a page, a neon frame sweeps the screen so you always see where it acted.
  • Never overrides securityPage text is treated as untrusted. Nebula can't switch off Rovian Defender or act on a site without asking you.

Rovian Defender

It checks every address before the page loads, stops look-alike sites and trackers, and inspects downloads before they're saved. It can only check known threats and common tricks, so it never calls a file guaranteed safe.
